# FileGuard-Protection
    FileGuard-Protection — программа на C++ для защиты файлов от несанкционированного удаления, изменения и создания в текущем каталоге на Linux. Использует inotify для мониторинга событий файловой системы и chattr для установки атрибутов неизменяемости (immutable). Поддерживает парольную защиту для управления режимом работы программы.
