# FileGuard Protection

Программа для защиты файловой системы в Linux, обеспечивающая контроль над файлами по заданным маскам. Предотвращает несанкционированное создание, удаление и изменение критически важных файлов.

## Компоненты проекта
В состав репозитория входят:
1. **`main.cpp`** — основной модуль защиты, использующий `inotify` для отслеживания событий файловой системы и атрибуты `chattr` для блокировки файлов.
2. **`hasher.cpp`** — вспомогательная утилита для генерации SHA256-хэша пароля, необходимого для настройки защиты.

## Требования
- ОС: Linux
- Компилятор: `g++` (поддерживающий стандарт C++11 и выше)
- Библиотеки: `libssl-dev` (OpenSSL для хеширования)
- Права: Программе требуются права **root** (`sudo`), так как управление атрибутами `chattr` доступно только суперпользователю.

## Установка и использование

### 1. Компиляция
Скомпилируйте оба модуля:

```bash
# Компиляция основного модуля
g++ -o fileguard main.cpp -lssl -lcrypto -lpthread

# Компиляция утилиты для хэширования
g++ -o hasher hasher.cpp -lssl -lcrypto
```

### 2. Подготовка конфигурации
Для работы защиты необходимо создать файл `template.tbl`.

1. **Генерация хэша пароля:**
   Запустите утилиту `hasher`. Если вы хотите установить свой пароль, отредактируйте переменную `pass` в исходном коде `hasher.cpp` и перекомпилируйте её.
   ```bash
   ./hasher
   # Скопируйте полученную строку (например: 5e884898da28...)
   ```

2. **Создание `template.tbl`:**
   Создайте файл `template.tbl` в той же директории, где будет находиться `fileguard`.
   Первая строка файла — это сгенерированный хэш, последующие строки — маски файлов (одна маска на строку).
   
   Пример `template.tbl`:
   ```text
   5e884898da28047151d0e56f8dc6292773603d0d6aabbdd62a11ef721d1542d8
   *.log
   config.json
   secret_data.txt
   ```

### 3. Запуск защиты
```bash
sudo ./fileguard
```

## Как это работает
- **Мониторинг:** Программа следит за текущей директорией через `inotify`. При появлении нового файла, соответствующего маске в `template.tbl`, программа автоматически удаляет его (если защита включена).
- **Управление защитой:** В консоли запущенной программы можно вводить пароль. Правильный пароль переключает состояние системы (ВКЛ/ВЫКЛ).
- **Безопасность:** Программа автоматически выставляет права доступа `0600` на файл `template.tbl` при запуске, чтобы защитить хэш пароля от чтения другими пользователями.

## Предупреждение
Данная программа предназначена для образовательных целей. Будьте осторожны при работе с атрибутами `chattr +i` в системных директориях, так как это может привести к нарушению работоспособности ОС.
